# TOPO APP — Aplicación de Topografía

Aplicación de topografía para **campo y gabinete**, con núcleo en el **control de niveles por capas** en pavimentación urbana y veredas.

**Estado:** diseño en progreso. Todavía no hay código — este repositorio contiene por ahora el documento de diseño.

## Documentación

- [Documento de diseño (2026-08-08)](docs/superpowers/specs/2026-08-08-app-topografica-design.md)

## Stack previsto

- Núcleo de cálculo en **TypeScript puro** (sin dependencias de UI/IO)
- **Capacitor** para Android (campo, Bluetooth Clásico SPP con estación total / GNSS)
- **Web** para Windows (gabinete)
- **Three.js** para el visualizador 3D
