Pistas y veredas: separación entre niveles

Llena cada conjunto como progresiva, lectura (o cota). Elige dos conjuntos por gráfica para ver su distancia, y usa el recuadro inferior para saber qué nivel registrar.

Punto de referencia (nivel)

Cada puesta del nivel tiene su cota BM y su lectura atrás. Si cambias la lectura (por ejemplo, de 1.000 a 1.500), todas las cotas de los conjuntos que usan esa puesta se actualizan. Para otro día, crea una puesta nueva y migra los conjuntos a ella.

Conjuntos de datos

Toca un conjunto para abrirlo y editarlo; al tocar otro se cambia. Progresiva en m. Si el tipo es «Cota», se usa el valor tal cual.

Tus datos se guardan en este navegador.

Nivel a registrar

Elige el conjunto y la progresiva: obtienes la cota y la lectura de mira en ese punto, siguiendo las pendientes ya establecidas. Si el conjunto no tiene línea en esa progresiva, se proyecta desde la línea más cercana. Puedes escribir varias progresivas separadas por coma.
